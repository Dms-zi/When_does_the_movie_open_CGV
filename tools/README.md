# 연결 확인

CGV가 열리는 PC에서 수동으로 한 번 접속을 확인하는 도구입니다. Python 3이 필요하고 추가 패키지는 없습니다. 이 도구는 자동 수집 서비스나 이용 허가를 대신하지 않습니다. 반복 조회·공개 알림 운영은 CGV의 허용 범위를 확인한 뒤 진행합니다.

Windows:

```powershell
py tools/check_cgv.py
```

macOS / Linux:

```sh
python3 tools/check_cgv.py
```

날짜 목록과 하루 시간표를 한 번씩만 조회합니다. 출력된 결과를 그대로 알려주시면 됩니다. 쿠키나 로그인 정보는 읽지 않습니다.

두 요청 모두 `httpStatus: 200`, `ok: true`이면 이 PC에서 일반 HTTP 조회가 됩니다. `rowCount: 0`이면 해당 응답의 목록은 비어 있습니다. 이것만으로 5분 자동 조회나 알림 발송이 검증된 것은 아닙니다.

`403`이 나오면 이 PC의 일반 HTTP 요청도 거절된 상태입니다. 브라우저에서 열린다는 사실만으로 자동 수집이 가능하다고 볼 수는 없습니다.
