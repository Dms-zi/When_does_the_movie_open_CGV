제목: 의정부 지점 상영정보 자동 조회 및 소규모 예매 오픈 알림 이용 문의

안녕하세요. 개인 비영리 프로젝트의 이용 가능 범위를 문의드립니다.

CGV 의정부 전체 상영관의 공개 상영정보를 운영자 Linux PC 한 대에서
5분 간격으로 확인하고, 약 10명의 이용자에게 선택한 영화의 새로운
예매 날짜가 열렸을 때만 웹 푸시 알림을 제공하려고 합니다.

웹 주소를 공유해 영화와 예매 가능 날짜를 확인하도록 할 계획입니다.
CGV 로그인 정보·쿠키는 수집하지 않고, 예매·좌석 확보·결제는 자동화하지 않습니다.
이용료나 광고 수익을 받지 않으며 실제 예매는 CGV 홈페이지로 연결합니다.

확인하고 싶은 사항은 다음과 같습니다.
1. 위와 같은 자동 조회, 영화명·예매 날짜 표시 및 알림 제공이 허용되는지
2. 허용되는 조회 API 또는 별도의 공식 연동 방법이 있는지
3. 지점·날짜 조회의 최소 간격과 일일 요청 한도, 표시해야 할 출처 문구가 있는지

검토 중인 방식은 날짜 목록 조회 1회와 날짜별 시간표 조회 D회로 구성되어,
조회 가능한 날짜가 D개이면 한 주기에 1+D회, 하루 최대 288×(1+D)회입니다.
사용자 수만큼 중복 조회하지 않으며, 허용해 주시는 호출 한도에 맞추겠습니다.
현재 서버 요청이 HTTP 403으로 거절되어 반복 조회는 중지했습니다.

관련하여 이 용도의 허용 여부 및 필요한 절차를 안내 부탁드립니다.
