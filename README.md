# 의정부 CGV 예매 알림

보고 싶은 영화를 골라두면 새 날짜의 예매가 열릴 때 알려줍니다. 의정부 CGV 전체 상영관을 확인합니다.

현재 자동 조회를 중지했습니다. CGV의 정보 이용 허용 여부와 서버 연결이 확인되기 전까지 영화 목록과 알림은 사용할 수 없습니다.

1. [웹사이트](https://dms-zi.github.io/When_does_the_movie_open_CGV/)에 접속합니다.
2. 알림을 받을 영화를 누릅니다.
3. **알림 켜기**를 누르고 브라우저 알림을 허용합니다.

5분 간격으로 확인합니다. 새 날짜가 없으면 알림을 보내지 않습니다. 이미 열린 날짜, 같은 날짜의 추가 회차나 취소표도 알리지 않습니다. 알림을 끄려면 **모든 알림 끄기**를 누르면 됩니다.

아이폰·아이패드는 iOS 16.4 이상에서 Safari로 접속하고 **홈 화면에 추가**한 뒤 알림을 켜주세요. 카카오톡 안에서 열었다면 Safari나 Chrome으로 다시 열어주세요.

화면에 연결 실패가 표시되면 영화 목록을 가져오지 못한 상태입니다. 마지막 확인 시각을 확인해 주세요. 알림은 조회 지연이나 기기 설정에 따라 늦을 수 있습니다.

직접 실행하거나 배포하는 방법과 비용 조건은 [web/README.md](web/README.md)에 있습니다. 운영자 Linux PC의 연결 확인 방법은 [tools/README.md](tools/README.md)에 있습니다.
