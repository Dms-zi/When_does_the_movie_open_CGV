같은 API를 새 탭에서 열기 CGV 의정부 열기

새 탭에서 JSON이 보이는 것과 이 페이지에서 JSON을 읽을 수 있는 것은 다른 검사입니다. 실패한 요청의 상태는 브라우저가 숨길 수 있어, 이 화면만으로 CORS와 네트워크 오류를 항상 구분할 수는 없습니다.

아이폰의 앱 요청도 확인하려면

  1. 위의 같은 API를 새 탭에서 열기 링크 주소를 복사합니다.
  2. 아이폰의 단축어에서 새 단축어를 만들고 URL 동작에 주소를 넣습니다.
  3. URL 콘텐츠 가져오기(GET), 빠른 보기 동작을 차례로 추가하고 실행합니다.

statusCode: 0과 data 배열이 나오면 단축어의 요청은 성공한 것입니다. 이는 iOS 앱의 연결 가능성을 판단하는 참고 검사이며, 별도로 개발한 앱의 실제 요청과 백그라운드 동작까지 검증한 것은 아닙니다.
