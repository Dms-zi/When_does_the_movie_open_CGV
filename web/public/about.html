알림 기준과 개인정보

어떤 알림을 보내나요?

CGV 의정부의 모든 상영관에서 선택한 영화의 새로운 예매 날짜가 처음 확인될 때 알립니다. 처음 확인한 기존 날짜, 같은 날짜의 회차 추가, 잔여 좌석 변화, 취소표에는 알리지 않습니다. 조회 오류나 변화 없는 결과도 푸시로 보내지 않습니다. 매진 후 같은 날짜가 다시 나타나도 중복으로 알리지 않습니다.

5분 간격으로 확인을 요청합니다. 스케줄 실행 지연, CGV 접속 제한, 기기 설정 때문에 알림이 늦거나 수신되지 않을 수 있습니다. 잔여 좌석과 실제 예매는 CGV에서 확인해 주세요. 화면에 마지막 성공 시각과 연결 상태를 표시합니다.

브라우저에 연결된 알림

회원가입은 없습니다. 알림 권한을 허용한 브라우저와 선택한 영화가 연결됩니다. 다른 브라우저나 기기에서는 다시 신청해야 합니다. 아이폰·아이패드는 지원하는 iOS에서 홈 화면에 추가한 웹사이트로 열어 알림을 허용해야 합니다.

저장하는 정보

서버에는 브라우저 푸시 주소와 암호화 공개 키, 선택한 영화, 등록 시각, 알림 발송 기록을 저장합니다. 브라우저에는 설정을 관리할 무작위 키와 중복 알림 방지 기록을 저장합니다. 이름, 이메일, CGV 계정·비밀번호는 받지 않습니다. 호스팅·푸시 제공자는 서비스 운영에 필요한 접속 정보를 처리할 수 있습니다.

‘모든 알림 끄기’를 누르면 서버의 해당 브라우저 등록 정보, 선택한 영화, 발송 기록이 삭제됩니다. 브라우저 권한만 끄거나 브라우저 데이터를 먼저 삭제하면 서버에서 즉시 삭제되지 않을 수 있습니다. 푸시 제공자가 등록 만료를 반환하면 삭제합니다.

비공식 오픈소스 프로젝트

CGV와 제휴한 서비스가 아닙니다. 기반 저장소는 cgv-open-push이며 AGPL-3.0 라이선스를 유지합니다. 이 버전의 전체 소스코드와 라이선스 다운로드를 제공합니다.
